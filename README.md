# Sample Test Survey

This repository contains an anonymized Test Survey prepared during structured manual testing training on a commercial application.

The document demonstrates how predefined test activities were executed, documented, and recorded during manual testing. All confidential information has been removed or replaced to comply with a non-disclosure agreement (NDA).

## Survey Overview

The survey includes:

- Test environment information
- Test type (Smoke, MAT, AT)
- Test execution date
- Test activities
- Expected results
- Actual results
- Tester information (anonymized)
- Execution comments

## Purpose

This document demonstrates my experience executing predefined test scenarios and documenting test execution results during manual testing.

>
